# V0.2 資料缺口、估值類型與模型假設

Price Intelligence 為核心，三個原入口不變：Budget Frontier → Comparable Engine → Price Intelligence → Trade-off Engine → Residual Value → Listing Comparison。拍照識車僅可作輔助入口，Vehicle Identity 僅可作後台去重工具；本版未新增兩者。

## 資料沿用

沿用 `model-catalog.json`、`fallback-models.json` 及 Carbook 公開 API，沒有新服務、套件或金鑰。Carbook 官方文件：https://carbook.tw/api/ （2026-09-25 查閱）。車款有年式價格與車身分類；估價 API 接受年式與萬公里數並回傳外部估值。fallback 為示範，並非實際觀測。

| 類型 | 使用範圍 | 不代表 |
| --- | --- | --- |
| Observed | 使用者提交的刊登價，明示未查證 | 真實成交價、車況驗證、獨立市場樣本 |
| Derived | Carbook 外部估值、年式基準、里程情境、價差、殘值 | 實測成交紀錄或經校準的預測 |
| Unknown | 缺少年式／價格／里程／配對樣本、估價 API 失敗 | 0 元、0 筆或沒有事故 |

## Year × Mileage Matrix

- 每次顯示選定年式前後 2 年，不顯示未來年式；缺少年式價格保留 Unknown，不拿鄰年冒充。
- 里程欄為 0、5、10、15 萬 km，加上使用者指定的里程（去重）。
- 假設參考里程 `max(0, asOfYear - year) × 1.5` 萬 km。
- 情境估值 `yearPrice × (1 + clamp((referenceMileage - mileage) × 0.01, -0.20, 0.20))`，四捨五入至 0.01 萬元。
- 每年 1.5 萬 km、每差 1 萬 km 調整 1%、上限 ±20% 都是產品情境假設，**未以市場樣本校準**。實际年式基準所含里程分布未知。
- `asOfYear` 在 UI 使用本地當前年份，測試固定 2026。跨年度情境值會改變。
- 不對所有矩陣格額外呼叫 API；降低請求量，也避免把不同模型輸出混合。原有單車外部估價獨立呈現。

## Budget Frontier V0.2

依使用者指定里程，計算每個已知年式的 Derived 情境。每車款選預算上限內最新年式；區分預算內與彈性區間，上限為預算 × (1 + stretch/100)。按年式新到舊、距預算差、名稱排序，最多顯示 12 車款。顯示下一個有資料年式及其情境差價；不推定中間缺漏年式。此為情境預算邊界，並非實際在售庫存或可買到的保證。

## Comparable Engine V0.2

- 相同 catalog segment；年式差 ≤2 年；同輸入里程下 Derived 價差 ≤25%。排除目標本身，依車款／年式去重。
- 依絕對價差、絕對年式差、名稱排序，最多 6 筆。每筆提供 `matchReasons`、`priceDelta`、`provenance`、`confidence`、`sampleSize` 與 `unknownFields`。
- `confidence.level = low` 表示未校準且缺少車況／配備資料的定性信心，**不是統計機率**。資料不足時不產生候選；矩陣格回傳 Unknown。
- `sampleSize = null`（UI：Unknown／未提供）。候選數是模型組合數，不是逐車觀測樣本數；Carbook 車款層級的 `listings` 也不冒充年式×里程配對樣本數。
- 空結果可能代表資料缺漏或篩選無候選，不代表市場沒有此類車。

## 仍缺資料

| 欄位 | 影響／本版處理 |
| --- | --- |
| 年式×里程逐車刊登、可靠 ID／觀測時間 | 無法確認獨立樣本、重刊、時效或分布；sample size Unknown |
| 同格樣本數、分位數／變異 | 無統計信賴區間，不產生百分比 confidence |
| 等級、動力、配備／選配 | 只按車身級距比較，不宣稱完全同規格 |
| 事故、泡水、維修、保養、實際車況 | 全部 Unknown，不因低價推定沒有問題 |
| 確認成交價及成交日期 | 刊登價不稱成交價，不訓練成交模型 |
| 年式價格的標準里程、地域、時間窗 | 里程調整只作透明情境，不作校準行情 |
| 殘值的年式／里程條件與模型方法 | 只展示 Carbook Derived 基準，明示方法未提供 |

## 驗證與部署邊界

先建立測試並確認 RED，再實作至 GREEN。Node 內建 assert/test 無外部依賴。測試涵蓋矩陣公式與邊界、缺值／零里程、fallback、預算硬上限、升級价差、Comparable 篩選／去重／樣本數、三入口保留與估價請求 timeout。

PR checks 僅驗證，不部署。原 Pages workflow 仍只在 main push（或手動）部署。本 PR 不自動 merge，也不更新正式網站。
